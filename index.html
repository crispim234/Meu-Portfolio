07

Notas técnicas

Coisas que quebrei e consertei construindo este site.

Nota 01 · Web APIs

Spotify embeds bloqueados em file://

Os players do Spotify não carregavam abrindo o arquivo direto — o navegador bloqueia iframe em file://. Resolvi carregando o iframe só no clique, o que de quebra deixou a página mais leve.

iframeLazy loadCORS

Nota 02 · JavaScript

Estado indefinido derruba a página inteira

O Snake tentava desenhar o tabuleiro antes do estado existir. Um TypeError travava o script inteiro e quebrava outras partes do site sem relação nenhuma com o jogo. Desde então, todo estado nasce com valor inicial seguro.

DebugEstadoCanvas

Nota 03 · CSS

Dark mode com CSS variables

O tema inteiro vive em variáveis CSS. Trocar de claro pra escuro é só mudar um atributo no HTML, sem JS recalculando nada. A preferência fica salva no localStorage.

CSS varslocalStorageDesign system
