App React + TypeScript + Vite

SPA acadêmica montada com tooling moderno de mercado — React com hooks, TypeScript e Vite, com ESLint garantindo consistência de código.

ReactTypeScriptViteESLint
Ver case study

O problema

Construir uma aplicação React do zero com configuração profissional, indo além do básico exigido em sala de aula.

Decisões técnicas

Escolhi Vite no lugar do CRA pela velocidade de build e hot reload quase instantâneo. TypeScript entrou para pegar erros em tempo de desenvolvimento, e ESLint para manter padrão de código do início ao fim.

O que aprendi

Tipagem de props e estado em componentes React, organização de pastas escalável e a diferença real que um bundler moderno faz no dia a dia.

07

Notas técnicas

Coisas que quebrei, consertei e aprendi construindo — inclusive este próprio site. Documentar o processo faz parte do trabalho.

Nota 01 · Web APIs

Spotify embeds bloqueados em file://

Ao desenvolver este portfólio, os players do Spotify não carregavam localmente: navegadores bloqueiam iframes de terceiros no protocolo file://. A solução foi injetar o iframe via JavaScript apenas no clique do usuário — padrão click-to-load. Bônus: a página carrega mais rápido, porque os embeds só pesam quando alguém realmente quer ouvir.

iframeLazy loadCORS

Nota 02 · JavaScript

Estado indefinido derruba a página inteira

O jogo Snake deste site desenhava o tabuleiro no carregamento — antes do estado existir. Resultado: TypeError que travava todo o script da página, quebrando funcionalidades sem relação com o jogo. Lição gravada: todo estado precisa de valor inicial seguro, e um erro não tratado nunca fica isolado — ele derruba tudo que vem depois.

DebugEstadoCanvas

Nota 03 · CSS

Dark mode com CSS variables

Todo o tema deste site vive em variáveis CSS: trocar de escuro para claro é mudar um atributo data-theme no HTML — zero JavaScript recalculando estilos. A preferência persiste em localStorage. Padrão simples, escalável e o mesmo usado em design systems de produção.
